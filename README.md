AI Impact on Student Performance

📌 Project Overview
This mini project analyzes the impact of AI usage on students' academic performance, study habits, and learning behavior using student-level data.

🎯 Objectives
- Analyze AI usage patterns among students
- Compare AI users and manual learners
- Study the relationship between AI dependency and performance
- Analyze study habits, concept understanding, and improvement rate

📊 Key Analysis
- Gender-wise Study Hours
- Top Used AI Tools
- Purpose of AI Usage
- AI User vs Manual Learner
- AI Dependency vs Final Score
- Grade-wise AI Usage
- AI Usage Time vs Improvement Rate
- Concept Understanding vs Performance

🛠️ Tools Used
- Microsoft Excel
- Power Query
- PivotTable & PivotChart
- Excel Functions

📈 Outcome
Created an interactive Excel dashboard to visualize AI usage patterns and their association with student performance.
